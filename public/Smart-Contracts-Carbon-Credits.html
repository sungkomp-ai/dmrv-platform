EXECUTIVE SUMMARY
Registry Overview

เอกสารนี้รวบรวมสัญญาอัจฉริยะ (Smart Contract) ที่ deploy บนเครือข่าย Polygon PoS สำหรับโครงการคาร์บอนเครดิตทั้งหมด 6 โครงการในระบบ TGO dMRV Platform โดยแต่ละโครงการจะมี smart contract แบบ ERC-721 (Non-Fungible Token) ที่ใช้ tokenizes หน่วยคาร์บอนเครดิตเป็น digital asset ที่สามารถตรวจสอบความถูกต้อง โอนกรรมสิทธิ์ และเกษียณ (retire) ได้แบบ transparent บน blockchain ทุก smart contract ผ่านการตรวจสอบโดย VVB และลงทะเบียนกับ TGO Carbon Registry ก่อนนำออกใช้งานในตลาดซื้อขาย

ARCHITECTURE
Smart Contract Stack

ระบบ Tokenization ใช้สถาปัตยกรรมแบบ modular โดยแต่ละโครงการมี smart contract ของตนเองบน Polygon PoS (Chain ID: 137) เพื่อแยกขอบเขตความรับผิดชอบและทำให้สามารถ upgrade หรือ audit ได้อิสระ โดยใช้มาตรฐาน ERC-721 ที่รองรับ metadata extension (ERC-721Metadata) เพื่อเชื่อมโยง token กับ certificate และ project record ในระบบ dMRV

Token Standard
ERC-721 NFT — แต่ละ token แทน batch ของคาร์บอนเครดิตที่ไม่สามารถ fungible ได้เนื่องจากต้องผูกกับ project, vintage และ methodology เฉพาะ
Chain
Polygon PoS — เลือก Proof-of-Stake chain เพื่อลด carbon footprint ของ transaction และค่า gas ต่ำ ทำให้เหมาะกับ micro-transactions
Access Control
ใช้ AccessControl (OpenZeppelin) — บทบาท MINTER_ROLE สำหรับ registry, VERIFIER_ROLE สำหรับ VVB, DEFAULT_ADMIN สำหรับ TGO
Metadata
URI schema ipfs://<cid>/<tokenId>.json — เก็บ project ref, methodology, cert ID, vintage, amount, geolocation แบบ immutable บน IPFS
Events
CreditMinted, CreditTraded, CreditRetired — emit ทุกการเปลี่ยนแปลงสถานะ เพื่อให้ indexer (The Graph) สร้าง queryable subgraph ได้
Upgradeability
ใช้ UUPSUpgradeable proxy pattern — สามารถ patch logic ได้โดย data layout คงที่ ผ่าน governance multisig ของ TGO + 2 VVB
